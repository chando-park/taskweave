# 승격 대상 분류

| 내용 | 대상 |
|---|---|
| 모든 작업에서 반복되는 행동 | `Runtime/AGENTS.md` |
| 명확한 시작·중간·완료 단계가 있는 작업 | 새 Skill 또는 기존 Skill |
| 긴 출력 양식·체크리스트·판정표 | Skill `references/` |
| 반복 실행할 결정적 변환·검사 | Skill `scripts/` 또는 Runtime script |
| 특정 저장소 아키텍처·빌드 규칙 | 해당 저장소 `AGENTS.md` 변경안 |
| 제품·조직이 공유해야 하는 확정 지식 | 회사 Workplan의 팀 위키 반영 후보 |
| 아직 한 번만 겪은 불편 또는 미검증 생각 | 개인 위키에 유지 |

## 상충 처리

- 기존 규칙과 같은 의미면 새 규칙을 추가하지 않고 기존 문장을 보강한다.
- 기존 규칙과 충돌하면 어느 규칙이 우선할지 승인받는다.
- 저장소 규칙과 개인 원칙이 충돌하면 저장소의 구체적 기술 규칙을 우선하고 개인 원칙의 적용 범위를 좁힌다.
- 팀 위키로 보낼 내용에는 개인 선호와 미확정 추정을 제거한다.
