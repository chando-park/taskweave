# 외부 코드 고지

이 프로그램은 공식 Model Context Protocol JavaScript SDK와 Zod를 잠금 파일의 버전으로 사용한다. 배포 패키지는 해당 패키지의 LICENSE 등 원래 고지를 함께 포함한다.

선택 기능 Archify는 [tt-a1i/archify](https://github.com/tt-a1i/archify)의 MIT 라이선스 코드다. `third-party/archify.lock.json`에 버전·commit·다운로드 해시를 고정한다. 선택 설치 시 원본 `LICENSE`, `THIRD_PARTY_NOTICES.md`와 포함 자산의 고지를 그대로 보존한다. 설치 전에는 외부 코드를 포함하거나 실행하지 않으며, 일상 실행 중 자동 다운로드·자동 업데이트·외부 업로드를 하지 않는다.

Archify가 포함하는 아이콘·폰트·기타 자산에는 자체 고지가 적용될 수 있다. 설치된 원본 고지를 제거하거나 이 프로젝트의 코드로 표시하지 않는다. 그림 생성 결과는 코드의 정확성이나 디자인 적합성을 증명하지 않는다.
