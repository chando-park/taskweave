# CDPower 안전한 제거

설명·제거 방법 질문만으로 실행하지 않는다. 사용자의 명시 제거 요청에만 적용한다. 현재 호스트만 요청했으면 해당 호스트, 양쪽 제거를 명시했으면 both를 사용한다. 어느 앱인지 모호하면 범위만 확인한다.

1. 이 스킬이 들어 있는 플러그인의 실제 설치 폴더를 확인하고, 그 안의 `mcp/src/installation.mjs`를 사용한다. 임의의 예전 checkout이나 다른 사용자 홈을 고르지 않는다.
2. `node <플러그인폴더>/mcp/src/installation.mjs --client <codex|claude|both> --uninstall`로 먼저 제거 대상·소유 연결·뷰어와 보존 대상을 읽는다. 공개/로컬 장터의 중복 설치가 모호하면 자동 선택하지 않는다. 사용자가 미리보기의 정확한 설치 하나를 골랐으면 단일 호스트와 `--plugin-selector <plugin@marketplace>`로 그 항목만 지정한다. 양쪽의 선택이 다르면 호스트별로 실행한다.
3. 사용자 요청과 같은 대상이며 모호함이 없으면 같은 명령에 `--apply`를 추가한다. 명시 제거 요청은 해당 제거의 승인이다. 기록 삭제 옵션은 전달하지 않는다. 보고서 작성·Workplan·별도 형식 검사를 선행 조건으로 만들지 않는다.
4. 실제 결과에서 제거한 설치와 연결, 사용자가 수정해서 보존한 지침, 남긴 다른 설치·뷰어, 실패·수동 정리 위치를 쉬운 한글로 설명한다. 일부만 성공했으면 전체 제거라고 보고하지 않는다.

코드·Workplans·Product Memory·프로젝트 지침의 사용자 작성 내용·설정·인증·Serena/Figma/Jira는 지우지 않는다. 브라우저 탭·다른 Node 프로세스를 닫거나 이전 작업 문서를 옮기지 않는다. 다른 설치가 쓰는 공용 뷰어는 남긴다. 소유권·실행 신원을 확인할 수 없으면 보존하고 이유를 알린다.

장터의 직접 삭제 버튼이 이 정리를 실행한다고 가정하지 않는다. `SessionEnd`를 제거 이벤트로 사용하지 않는다. 삭제 후 현재 대화에 이미 읽힌 지침은 사라지지 않으므로 새 대화를 시작하도록 안내한다. 아직 남은 연결을 확인해야 하면 남아 있는 설치본의 같은 제거 도구를 사용하며 추측으로 전체 지침 파일을 삭제하지 않는다.
