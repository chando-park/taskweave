# 글쓰기의 자료·규칙·검토 기준

진행 방식·기록은 [공통 작업 흐름](task-workflow.md)에서 선택한다. 이 문서는 글쓰기의 독립 기준과 검토 차이만 소유한다. 제공된 전문 문서·슬라이드·문체 스킬을 필요할 때 사용하고 해당 기능을 재구현하지 않는다.

## 요약

- 원문과 대상 독자·분량·사용처를 확인한다. 요청에서 알 수 없는 정보 중 결과를 실질적으로 바꾸는 것만 묻는다.
- 원문 문장·표·수치·날짜·조건·결론을 기준으로 작성한다. 사실, 원문의 주장, 추론을 구분하고 원문에 없는 인과·확정을 보태지 않는다.
- 작성 후 원문으로 돌아가 핵심 누락·수치/단위·조건·왜곡·합의한 분량을 직접 대조한다. 요약문이 존재한다는 사실만으로 검토 통과라고 하지 않는다.
- 대화 요약 요청은 대화로 전달한다. 파일 저장·원본 덮어쓰기·외부 공유를 별도로 요청하지 않았다면 수행하지 않는다.

## 대본 수정

- 원래 의도와 합의한 청중·말투·길이·발화 상황을 기준으로 삼는다. 한 문장 수정은 그 문장과 의미 연결에 필요한 주변만 확인한다.
- 의미·말투·분량을 수정한 부분과 관련된 연결만 검토한다. 진행 방식과 필요한 승인은 공통 흐름을 따른다.
- 사실·약속·수치·인용을 임의로 바꾸지 않는다. 설득·의도·사실관계에 중요한 선택이 필요하면 먼저 확인한다.
- 수정 뒤 원문 의도·청중·말투·길이와 대조하고 낭독 관점에서 호흡·연결을 검토한다. 실제 낭독이나 재생을 하지 않았다면 수행했다고 표현하지 않는다.

## 관찰 기록과 처음 쓰는 종류

- 보육일지는 제공된 관찰 메모와 기관 양식을 자료로 삼는다. 기관 기준은 해당 작업에만 적용하며 모든 글쓰기의 규칙으로 일반화하지 않는다.
- 실제로 관찰하지 않은 행동·발언·평가를 만들지 않는다. 메모에 없는 사실을 추가해 달라는 요청은 관찰 여부를 확인하고, 확인할 수 없으면 빈칸이나 미확인으로 남긴다.
- 작성 후 인물·시점·행동·발언·조건과 중요한 누락을 메모에 대조하고 요청한 양식·분량을 확인한다. 학부모 안내문으로 바꿀 때도 관찰 사실은 유지하고 독자·목적·표현에 맞게 바뀐 부분을 검토한다.
- 아동 등 개인정보의 외부 공유·발송 권한은 작성 요청에서 추정하지 않는다. 실제 전송은 별도 권한을 확인한다.
- 처음 보는 글도 제공된 목적·원문·산출물·제약을 재사용해 기준을 정한다. 결과에 필요한 누락만 묻고 새 필수 입력 양식·스킬을 먼저 만들지 않는다.

현재 글에서의 축약·독자 변경 등 후속 요청은 [공통 피드백 절차](acceptance-feedback-loop.md)를 따른다. Git·MCP 연결·프로젝트 등록은 글쓰기의 선행 조건이 아니다.

## 결과 전달

수정본과 필요한 짧은 변경 이유를 제공한다. 사실·누락·표현·형식 중 실제 확인한 것과 확인하지 못한 원문/외부 사실을 구분한다. 앱 테스트·코드 커버리지·Git 등록·Workplan·지식 평가를 글쓰기의 기본 완료 조건으로 만들지 않는다. 회사 기록 정책이나 사용자 지정 산출물 형식이 있으면 그 범위만 추가한다.
